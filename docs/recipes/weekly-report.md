# 配方：项目周报

**场景**：每周花几分钟，让 Agent 把这个项目这一周的 AI 会话整理成一份周报。
不用翻聊天记录，也不用自己回忆。

## 提示词（复制给 Agent）

```text
用 agent-archive 的 MCP 工具生成本周项目周报。

项目：{{项目路径}}
时间范围：{{开始日期}} 至 {{结束日期}}

步骤：
1. 调 project_timeline，拉这个项目的会话清单（只给元数据，不读正文）。
2. 筛出时间范围内的会话。对每场先调 read_session_summary 看有没有现成摘要；
   没有摘要的，按标题判断值不值得读。
3. 对值得读的会话用 read_session 分段读（默认 8000 字），只提取：
   这场在做什么、结论是什么、留下了什么问题。
4. 如果项目有交接背景，调 project_brief 补充「上一段做到哪」。

输出格式：
- 本周概览：3 句以内
- 按主题分组的进展：每条带日期和会话 id
- 关键决策与结论
- 遗留问题 / 下周建议（标「建议」）

规则：只写记录里有依据的事；没有记录的主题不要凑；每个结论后面标会话 id。
```

## 工具顺序

| 步骤 | 工具 | 用途 |
|---|---|---|
| 1 | `project_timeline` | 拿会话清单和时间范围 |
| 2 | `read_session_summary` | 先看有没有现成摘要，省成本 |
| 3 | `read_session` | 只读值得读的会话，分段 |
| 4 | `project_brief`（可选） | 补上一段交接背景 |

## 为什么有效

- `project_timeline` 只返回元数据，几百场会话也不会把上下文撑爆。
- `read_session_summary` 是缓存过的摘要，有就直接用；没有才读正文。
- 周报是**你的模型**写的，不是我们替你调模型——不想花模型钱就只看事实清单。
